ABYSS HUNTER — asset slots for ludo.ai art
==========================================

Save each exported image here with EXACTLY these filenames.
The game loads them automatically if present (no code change needed).

LOGO (shows big on the splash screen):
  logo.png          (transparent PNG, ~1600x500)

FISH (side view, facing RIGHT, transparent background):
  fish-minnow.png   small teal minnow
  fish-darter.png   blue darter
  fish-ray.png      purple manta ray
  fish-angler.png   orange anglerfish (with lure)
  fish-golden.png   golden koi
  fish-levia.png    big boss leviathan

CANNON (optional, the player's turret at the bottom):
  cannon.png

Notes:
- Always export as PNG with transparent background.
- Fish must face RIGHT; the game flips them automatically.
- If a file is missing, the game uses its built-in drawn art instead.
